Apache Ossie · Community Roadmap

Future of the Open Semantic Layer

Three tracks of work shaping how organizations define, share, and query business metrics — from a shared core model to an AI-native semantic layer.

Working Now
Current Working Groups
Active community efforts with ongoing discussions and pull requests.
Metric Semantics & Core Model
Richer aggregation, grain, and filter semantics. A documented spec of community-agreed metric behavior.
Catalog Integration & Semantic Services
Polaris-style catalog integration. Standalone semantic registry with discovery, versioning, and access control.
Ontology & Semantic Interoperability
Canonical business concept layer with schema mappings. Support for non-tabular data models.
Coming Next
Future Efforts
Community-voted priorities not yet in active development.
Dataset Abstraction & Logical Modeling
Decouple semantic definitions from physical storage. Logical and reusable datasets.
Semantic Query Language & Reference Engine
Standard query interface. Reference Ossie-to-SQL compiler with a conformance test suite.
SQL Dialect & Execution Boundaries
Dialect handling. Clear separation between definition and execution. Optional templating.
Dimensions, Hierarchies & Time
Hierarchical dimensions. Standardized time semantics and calendar abstractions.
AI-Native Semantic Layer
Standardized AI context metadata. Verified queries and controls over AI exposure to business metrics.
Governance, Identity & Validation
Stable identifiers. Validation standards and governance certification frameworks.
Domain-Specific Semantic Models
Reusable templates for SaaS, finance, and retail verticals.
Incremental
Enhancements & Additions
Backward-compatible improvements to usability, metadata, and ecosystem reach.
Naming, Terminology & UX
Rename "Field" → "Dimension." Add display names and cleaner terminology across the spec.
Data Types & Field Semantics
Units, currencies, and field type classifications — including PII tagging.
Extended Metadata
Optional, backward-compatible additions: display formats, default aggregation, and similar.
Developer Experience & Docs
Usage guides, modeling best practices, and Markdown support in descriptions.
Specialized Capabilities
Geospatial types, date spines, and audience/segment definitions.
Tooling & Ecosystem Support
Validators and converters for Snowflake, GoodData, Salesforce, Polaris, and Microsoft.
