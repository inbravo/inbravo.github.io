AI Engineering — Three Disciplines

Building production AI agents requires three distinct engineering practices. Each answers a different question. Each fails independently if neglected.

Discipline 01
Context Engineering
What the agent knows
Engineering the governed layer between raw data and the LLM. Semantic models, ontologies, metric views, and governed defaults that resolve ambiguity before the model sees the question. The same model on different context layers produces radically different accuracy.

Discipline 02
Harness Engineering
How the agent runs
Engineering the scaffold that turns an LLM into an agent. MCP server design, tool definitions, memory architecture (in-context · episodic · semantic · procedural), and orchestration patterns that govern how the agent reasons and acts.

Discipline 03
Agent Testing
How you prove it works
Engineering the evaluation harness that proves an agent is correct, durable, and compliant. Output scoring, trajectory scoring, ontology-derived evals, and CI/CD regression gates. Covers all major eval frameworks and AI lab approaches.
